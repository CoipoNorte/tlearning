# 🎨 [tlearning](https://coiponorte.github.io/tlearning/)

Guía interactiva para aprender Tailwind CSS v4 desde cero. Landing page con 14 secciones que cubren todas las utilidades, configuración con @theme, @utility y demos en vivo.

![Tailwind](https://img.shields.io/badge/Tailwind_CSS-v4-06b6d4?logo=tailwindcss)
![React](https://img.shields.io/badge/React-18-61dafb?logo=react)
![Vite](https://img.shields.io/badge/Vite-5-646cff?logo=vite)

## 🔗 Temas cubiertos

Setup v4 · Colores · Spacing · Flexbox · Grid · Tipografía · Bordes · Efectos · @theme · Animaciones · Responsive · Estados · @utility · Componentes

## 🛠️ Tecnologías

- **Tailwind CSS v4** — Framework CSS utility-first
- **React 18** — Biblioteca de UI
- **Vite** — Build tool
- **Lucide React** — Iconos

## 🚀 Ejecutar

```bash
npm install
npm run dev
```
